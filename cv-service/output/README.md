# output/

Gitignored. Generated by `run_pipeline.py` on each run:

- `annotated.mp4` — input video with vehicle/plate boxes and OCR text overlaid
- `events.json` — one JSON `DetectionEvent` per finalized track
- `evidence/track_<id>_frame.jpg`, `evidence/track_<id>_plate.jpg` — best-reading evidence images per track
